# ns/shapes/ — platform-level SHACL shapes

Shapes validating config-conforming data, workflow definitions (ii-backend ts-0003), and HCS message payloads (ts-0002). [`legacy-shapes.ttl`](legacy-shapes.ttl) holds the nine shapes carried forward from the legacy `/ns/` JSON-LD as prune candidates; their `sh:in` enumerations become SKOS concept schemes in `ns/config/`. Standard-specific shapes live in private per-standard graphs (ADR-0005), not here. **Platform-only**: content is not publicly pinned; catalogued with `dcterms:accessRights "platform-only"`. See [ADR-0002 §4 and the visibility section](../../docs/adr/0002-platform-semantic-artifact-inventory.md).
