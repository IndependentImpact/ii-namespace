# ns/vocab/ — II Platform vocabulary

Classes and properties the platform needs that no domain ontology covers. Successor to the deprecated legacy `/ns/` vocabulary — see [ADR-0001](../../docs/adr/0001-deprecate-legacy-ns-vocabulary.md) and [ADR-0002 §2](../../docs/adr/0002-platform-semantic-artifact-inventory.md) for scope and sources. Design rule: mint nothing that AIAO, claimont, impactont, or the Hashgraph Ontology already provides.
