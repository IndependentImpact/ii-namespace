# ns/vocab/ — II Platform vocabulary

Classes and properties the platform needs that no domain ontology covers. [`vocab.ttl`](vocab.ttl) carries forward the legacy `/ns/` vocabulary in governed Turtle form: all 12 classes and 48 properties, with `skos:editorialNote "Carry-forward review: …"` marking terms whose retention is decided per-term in review — see [ADR-0001](../../docs/adr/0001-rebuild-legacy-ns-vocabulary-in-governed-form.md) and [ADR-0002 §2](../../docs/adr/0002-platform-semantic-artifact-inventory.md) for scope and sources. Design rule: define nothing that aiao, claimont, impactont, infocomm, dcterms, or Bhash (the Hashgraph Ontology) already provides.
