# ii-namespace
Repository for hosting Independent Impact's semantic namespace.

II will make extensive use of externally hosted and managed ontologies and vocabularies. II will, in addition, also maintain its own namespace that will (a) define terms, classes and properties related to II's operations, and (b) where needed, extend properties and classes of externally hosted and managed ontologies and vocabularies. 

This repo is for documenting II's entire semantic namespace, i.e., (a) identifying the external ontologies and vocabularies used by II, along with how they are applied by II, and (b) hosting II's own namespace.
